## Getting Started with [`uv`](https://github.com/astral-sh/uv)

```terminal
uv venv
source .venv/bin/activate
uv pip install "mcp[cli]" llama-cpp-python
```

## Running MCP with `dev` Command

```terminal
mcp dev server.py
```
